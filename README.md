<h1 align="center">SciRepro</h1>

<p align="center"><strong>从论文图件，回到可以运行、比较和检验的研究过程</strong></p>
<p align="center">简体中文 · <a href="README.en.md">English</a> · <a href="scirepro/SKILL.md">Skill 规范</a></p>

SciRepro 是面向 Codex 的科研图件复现 Skill。它只追溯与目标图有关的数据—方法—参数—绘图链，尽快运行最有证据支撑的路线，并依据科学观测量判断结果，而不是把发表图片临摹得更像。

最终结果可以是成功复现、诚实受限的替代验证、有价值的负面结果，或一个说明如何解除的明确阻断。程序运行成功不等于论文主张获得支持。

它同时处理两种**证据边界不同**的工作：有论文及目标相关证据支撑时，可以复现或检验生成图件的研究过程；仅有图片时，只重建图片本身能够可靠识别的内容。后者不是原始实验、数据或论文结论的复现。

## 安装与调用

```text
使用 $skill-installer 安装 https://github.com/SciToolsmith/scirepro/tree/main/scirepro
```

```text
使用 $scirepro 复现这篇论文的图 1、图 6 和图 7。
```

支持三种输入，也支持一次处理多个目标：

- 论文 + 上传的目标图片；
- 论文 + 图号或面板标识，由 Skill 获取并核验目标；
- 仅目标图片，先判断像素中的信息是否足以可靠重建，再选择图像派生重构或给出明确阻断。

各目标可以采用不同实现或运行环境；它们的成功、失败和阻断分别判断，互不掩盖。

## 能做什么样的复现

前两种输入可以支撑**科研过程复现或检验**：Skill 结合论文、目标图及可获得的代码、数据和参数，追溯目标相关的数据—方法—参数—绘图链。结果可以是原始条件下的重算、机制复现、替代验证，或因关键证据缺失而阻断；不会把一次成功运行误写成对论文全部主张的证明。

论文没有报告全部细节时，SciRepro 不会把每个缺失值都当作阻断。它按未知量能否改变目标科学观测量和结论来处理：关键未知量需要核实、推导或做最小范围验证；非关键控制量采用有依据、明确标注且可复跑的假设，只有当合理取值可能改变验收时才做小范围对照；偶然随机实现和非科学外观细节固定一次即可。权威证据已经表明原案例无法精确重算、但机制仍可检验时，Skill 会尽早转为机制复现，而不是继续考据或追求 1:1 像素。假设不会冒充作者原值，也不会为了贴图事后挑选。

第三种输入属于**图像派生重构**，不与科研过程复现混称。Skill 先判断可辨识性：

- 坐标、刻度、图例和数据标记足够清晰时，可在明确像素误差范围内数字化并重绘可见数据；
- 只有部分信息可辨识时，只重建可辨识的曲线、布局、相对趋势或标注，并保留未知部分；
- 只能辨识外观时，只有用户目标确为外观或版式重建才会交付，并明确标注为外观重建；
- 关键数据、坐标映射或生成方法无法从像素辨识，且用户要求的结果依赖这些信息时，直接说明无法完成何种复现、最少还需要哪些材料，不以猜测补全；
- 算法流程图、机制图等语义图终端移交给 `sci-diagram-pptx`。

因此，“图上可读数据的重绘”“图形外观重建”和“生成该图的科研过程复现”是不同的成果；SciRepro 会在交付中标明实际达到的是哪一种。

## 工作方式

```text
确认目标 → 理解图中科学观测量 → 追溯相关生成链 → 选择诚实路线
→ 尽快得到并保留第一个有用 V0 → 科学验收 → 一个客户文件夹
```

- 优先使用作者原生代码、数据格式和运行环境所携带的证据，但最终路线由目标决定。独立推导、移植或交叉验证也可以是正确选择；替代内容始终明确标注。
- 缺失本身不触发联网。先使用论文、目标图和用户已提供的材料；只检索会改变路线、结论、安全、显著成本或交付物的关键未知量，并在每项关键证据出现后取消已经失效的搜索。
- 安全、创建式、资源有界的本地工作直接进行，不生成前置网页或形式化批准流程。登录、付费、受限资源、上传、覆盖、发布或实质科学选择才会询问。
- 尽快产生并保留第一个有科学意义的 V0。只有当新搜索分支、委派、广度探查或额外科学运行能解决一个会改变决定的明确未知量时，才扩展调查。
- 只有当论文主张或负面结果的解释依赖稳健性时才做敏感性分析；没有统一固定的迭代次数。
- 保留与结论有关的失败和反例，不迎合原图挑选随机种子，也不把复现失败直接解释为研究不端。

## 流程图与机制示意图

算法流程图、机制图、技术路线图和科研架构图会终端移交给 `sci-diagram-pptx`，而不是被当作定量图复现。用户未指定格式时，默认交付一个原生可编辑 PPTX 和一张 PNG 预览。构建源码仅在用户明确要求、且能够清洁复跑时提供。

缺失的伴生 Skill 只能从固定公开提交按窄边界自动部署；不会覆盖已有安装，也不会隐式安装其运行时、Office、字体或系统软件。

## 客户会得到什么

有持久成果时，SciRepro 从内部临时工作区组装一个简洁客户文件夹，包含：

- 一份先讲科学结论、再说明限制的入口说明；
- 每个目标的主要图件或可编辑成果，以及必要的比较与验收证据；
- 可重新运行所需的代码、配置、命令和实际依赖；
- 关键假设、替代内容、负面结果、剩余差异和权利边界。

原始搜索记录、调试日志、QA 覆盖图、内部 manifest、机器广度扫描和无关中间版本不会作为客户交付物。必要事实会被摘要，必要证据会以面向用途的文件提供。
