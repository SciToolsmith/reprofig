<h1 align="center">SciRepro</h1>

<p align="center"><strong>从论文图件，回到可以运行、比较和检验的研究过程</strong></p>
<p align="center">简体中文 · <a href="README.en.md">English</a> · <a href="scirepro/SKILL.md">Skill 规范</a></p>

SciRepro 是面向 Codex 的科研图件复现 Skill。它接收论文与目标图片、论文与图号，或仅目标图片，追溯与目标有关的数据—方法—参数—绘图链，执行最有证据支撑的路线，并用预先定义的科学观测量验证结果。

它的目标不是把像素临摹得更像，而是交付可重跑的证据：成功的复现、诚实受限的替代验证、有价值的负面结果，或一个明确且可解除的阻断原因。

## 快速开始

```text
使用 $skill-installer 安装 https://github.com/SciToolsmith/scirepro/tree/main/scirepro
```

```text
使用 $scirepro 复现这篇论文的图 1、图 6 和图 7。
```

支持三种入口：

- 论文 + 上传的目标图片；
- 论文 + 图号或面板标识，由 Skill 获取并核验目标；
- 仅目标图片，执行明确标注的图像派生重构，不冒充原始实验或数据复现。

算法流程图、机制图、技术路线图和科研架构图会移交给 `sci-diagram-pptx`。缺失的伴生 Skill 可从固定公开提交按严格边界自动部署；不会隐式安装其运行时、系统软件或覆盖现有安装。

## 工作方式

```text
锁定目标 → 理解科学观测量 → 追溯相关生成链 → 选择诚实路线
→ 运行并保留 V0 → 科学验收与有依据的迭代 → 一个结果文件夹
```

- 优先保留作者原生实现所携带的证据，但路线最终由用户目标决定。独立实现、推导、移植或交叉验证可以是正确选择；任何替代都必须显式说明。
- 只核验会改变目标结果或结论的公式、参数、数据和环境，不审计整篇论文或整台机器。
- 安全、创建式、资源可控的本地路线直接执行；登录、付费、共享许可证、GPU/云资源、覆盖、上传、发布等实质影响才询问用户。
- 计划中的资源上限默认是声明值。只有执行机制确实限制或测量了资源，才会把它报告为已强制或已观测。
- 始终保留未迎合原图调参的 V0。后续运行必须来自明确诊断或可检验假设；当不会再增加科学信息时停止。
- 区分执行失败、验证失败和论文主张未获支持。复现失败本身不等于研究不端。

## 最终交付

一旦产生持久成果，SciRepro 交付一个 `scirepro-run-<id>/` 文件夹，集中保存目标与来源边界、可重跑代码和命令、输入与参数、运行环境、V0 与后续有依据的版本、比较和验收结果、假设、许可证、日志及剩余差异。多目标任务共享的证据只保存一次，各目标的成功、失败或阻断相互隔离。
